wlperch is a quick-settings popup, status bar, lock screen and desktop helper for the sway compositor, in one binary.

**0.4.0 (early / pre-release).** Expect rough edges; bug reports are welcome.

### Changes since 0.3.0
- **Idle and locking, without swayidle.** wlperch locks after `[lock] idle_lock_seconds` (with its countdown), turns the monitors off after `screen_off_seconds`, and sooner once locked (`locked_screen_off_seconds`). With logind (systemd or elogind) it also locks before sleep and on `loginctl lock-session`; without it everything else still works. Setup's Idle card switches over from swayidle (with backups and a switch back).
- **What keeps the screen awake:** idle inhibitors (videos, `inhibit_idle` rules, controller tools), fullscreen games (wine / .exe, Steam, gamescope, Lutris; `[lock] games_keep_awake`) and holds: `wlperch idle hold <name> [--pid PID]` / `release` / `status`. A hold with `--pid` ends when that process exits, e.g. for a game-streaming session. The bar's eye shows every reason.
- **Optional systemd service** for the daemon (restarted if it crashes), from the Background service card. Sway's `exec` stays the default.
- **wlperch's own wallpaper** instead of swaybg: a crossfade on every change, the dark / light sets of wallpapers (pick them on the Look page) and an optional new picture every few minutes (`[wallpapers] rotate_minutes`).
- **A redesigned setup window:** a sidebar of pages (Overview, Basics, Bar & panels, Look, Lock & idle, Notifications, Launcher, Time tracking, SSH keys), each with its components and their settings together; search with Ctrl+F; compact cards.
- **Bar:** a speaker on the workspace of the app that plays audio.
- **Neovim** follows the theme only through setup's Neovim theme plugin.

### Upgrade notes
- `[theme] nvim_file` (`~/.vimrc.color`) is gone: install the Neovim theme plugin (setup → Look) and remove any `.vimrc.color` lines from your nvim config. Plain Vim no longer follows the theme.
- With wlperch's idle, a script that stops swayidle no longer pauses locking: use `wlperch idle hold` instead.
- `[theme.dark|light] wallpaper` is only used while that mode has no wallpapers marked on the Look page.
- Updating from 0.3.0 works with the update button (or `wlperch update`).

### Platform
- Linux, x86_64 or aarch64 (ARM64)
- Wayland with sway (it uses sway's IPC); some parts also work on other wlroots compositors
- glibc 2.34 or newer (Debian 12, Ubuntu 22.04, Fedora 35 and later)

The aarch64 build is cross-compiled. Its unit tests pass under qemu, but it has not been tried on real ARM hardware yet.

### Runtime dependencies
Most sway desktops already have these installed.
- **Fedora:** `libwayland-client libwayland-egl libglvnd-egl mesa-libEGL libxkbcommon systemd-libs pam-libs fontconfig freetype libstdc++`
- **Debian / Ubuntu:** `libwayland-client0 libwayland-egl1 libegl1 libegl-mesa0 libxkbcommon0 libsystemd0 libpam0g libfontconfig1 libfreetype6 libstdc++6`

Optional tools for some panels (README, "Building"): `pactl`, `busctl`, `curl`, `wl-copy`, `bluetoothctl`, `wlsunset`.

### Install
```sh
tar xzf wlperch-0.4.0-x86_64-linux.tar.gz   # or the aarch64 tarball
cd wlperch-0.4.0-x86_64-linux
./wlperch
```
`./wlperch` opens the setup window. From there it copies itself to `~/.local/bin/wlperch` and can set up the sway integration, the waybar buttons, the config file and the other parts. Each file can be previewed before it is written. You can also copy `wlperch` to `~/.local/bin` yourself and use the files in `contrib/` (see the README).

Check the download with `sha256sum -c SHA256SUMS`.

The tarballs contain the binary, the README, the `contrib/` sway, waybar and Neovim files, and the license texts of the embedded fonts, the emoji data, Dear ImGui and the Odin core library (`licenses/`).
