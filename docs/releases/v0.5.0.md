wlperch is a quick-settings popup, status bar, lock screen and desktop helper for the sway compositor, in one binary.

**0.5.0 (early / pre-release).** Expect rough edges; bug reports are welcome.

### Changes since 0.4.0
- **Fix: fullscreen games and `wlperch idle hold` keep the screen awake on sway 1.12.** sway 1.12 ignores idle inhibitors on surfaces that aren't on screen; wlperch now holds its inhibitor on a 1×1 transparent layer surface, so neither the lock nor monitors-off happens while a game runs.
- **Several workspaces per project on one monitor:** `Pallas 1`, `Pallas 1b`, `Pallas 1c`, … Keys (editable in setup's Sway card): `$mod+Alt+p` new workspace, `$mod+]` / `$mod+[` next / previous, `$mod+Shift+]` / `$mod+Shift+[` move the window there, `$mod+Alt+Shift+p` move it to a new one (`wlperch track new|next|prev|move-next|move-prev|move-new`). Each monitor returns to the project workspace it showed last.
- **Time tracker:** only real input counts as presence. The bar's eye, videos, games and holds keep the screen on and unlocked, but no longer keep the timer running (needs ext-idle-notify v2: sway 1.10+).
- **Time panel:** browse past days with ‹ / › (or the arrow keys), Today, or a click on the week chart. Also fixed: on the days summer time starts or ends, "today" now starts at midnight.
- **Notifications show the workspace they came from**, in the project's colour, in the popup and (dimmed) in the history; a click goes there. Claude Code's notifications find their terminal window.

### Upgrade notes
- Click **Update** on setup's Sway integration card to get the new key bindings.
- The notification history file changed format again (WLN3): 0.5.0 reads older ones, but going back to 0.4.0 or earlier afterwards loses the history.
- Updating from 0.4.0 works with the update button (or `wlperch update`).

### Platform
- Linux, x86_64 or aarch64 (ARM64)
- Wayland with sway (it uses sway's IPC); some parts also work on other wlroots compositors
- glibc 2.34 or newer (Debian 12, Ubuntu 22.04, Fedora 35 and later)

The aarch64 build is cross-compiled. Its unit tests pass under qemu, but it has not been tried on real ARM hardware yet.

### Runtime dependencies
Most sway desktops already have these installed.
- **Fedora:** `libwayland-client libwayland-egl libglvnd-egl mesa-libEGL libxkbcommon systemd-libs pam-libs fontconfig freetype libstdc++`
- **Debian / Ubuntu:** `libwayland-client0 libwayland-egl1 libegl1 libegl-mesa0 libxkbcommon0 libsystemd0 libpam0g libfontconfig1 libfreetype6 libstdc++6`

Optional tools for some panels (README, "Building"): `pactl`, `busctl`, `curl`, `wl-copy`, `bluetoothctl`, `wlsunset`.

### Install
```sh
tar xzf wlperch-0.5.0-x86_64-linux.tar.gz   # or the aarch64 tarball
cd wlperch-0.5.0-x86_64-linux
./wlperch
```
`./wlperch` opens the setup window. From there it copies itself to `~/.local/bin/wlperch` and can set up the sway integration, the waybar buttons, the config file and the other parts. Each file can be previewed before it is written. You can also copy `wlperch` to `~/.local/bin` yourself and use the files in `contrib/` (see the README).

Check the download with `sha256sum -c SHA256SUMS`.

The tarballs contain the binary, the README, the `contrib/` sway, waybar and Neovim files, and the license texts of the embedded fonts, the emoji data, Dear ImGui and the Odin core library (`licenses/`).
