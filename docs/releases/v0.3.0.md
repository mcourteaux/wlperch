wlperch is a quick-settings popup, status bar, lock screen and desktop helper for the sway compositor, in one binary.

**0.3.0 (early / pre-release).** Expect rough edges; bug reports are welcome.

### Changes since 0.2.0
- **Paying projects and hourly rates.** Mark a project as a paying job and give it an hourly rate (the pencil next to it in the Time panel). Paying projects get a cash icon; the panel, the bar's timer tooltip and the export preview show what you earned. The currency is a setting (`[timetracker] currency`, default `€`).
- **Claude's background work can count.** Per project, wlperch can count the time a Claude Code terminal is working on that project's workspace, even when you're elsewhere or away. It watches window titles for Claude's spinner (◐/◑, also when frozen) until it shows ✳, and only while a `claude` process runs in that terminal. Overlaps with your own time count once. The Time panel shows when a project is being counted this way.
- **Grouped notifications.** Messages from one app that arrive in a row show as one group (with each sender's picture), and identical ones fold into one entry with a counter (×7). A new message replaces that app's popup instead of stacking.
- **Bar:** the timer is in the tracked project's colour; right-click a workspace to switch only that monitor, without the group lock moving the others.
- **Setup:** click the "Set up" or "Needs attention" tile to make the components that aren't set up pulse.
- **Release builds** are now made by `tools/release/release.sh`, reproducibly, from pinned and checksummed inputs.

### Upgrade notes
- **CSV export:** rows have two new columns at the end, `rate` and `amount`, and Claude's time is labelled `claude`.
- **Notification history:** the file format changed. 0.3.0 reads the old history, but going back to 0.2.0 afterwards loses it.
- Updating from 0.2.0 works with the update button (or `wlperch update`).

### Platform
- Linux, x86_64 or aarch64 (ARM64)
- Wayland with sway (it uses sway's IPC); some parts also work on other wlroots compositors
- glibc 2.34 or newer (Debian 12, Ubuntu 22.04, Fedora 35 and later)

The aarch64 build is cross-compiled. Its unit tests pass under qemu, but it has not been tried on real ARM hardware yet.

### Runtime dependencies
Most sway desktops already have these installed.
- **Fedora:** `libwayland-client libwayland-egl libglvnd-egl mesa-libEGL libxkbcommon systemd-libs pam-libs fontconfig freetype libstdc++`
- **Debian / Ubuntu:** `libwayland-client0 libwayland-egl1 libegl1 libegl-mesa0 libxkbcommon0 libsystemd0 libpam0g libfontconfig1 libfreetype6 libstdc++6`

Optional tools for some panels (README, "Building"): `pactl`, `busctl`, `curl`, `wl-copy`, `bluetoothctl`, `wlsunset`.

### Install
```sh
tar xzf wlperch-0.3.0-x86_64-linux.tar.gz   # or the aarch64 tarball
cd wlperch-0.3.0-x86_64-linux
./wlperch
```
`./wlperch` opens the setup window. From there it copies itself to `~/.local/bin/wlperch` and can set up the sway integration, the waybar buttons, the config file and the other parts. Each file can be previewed before it is written. You can also copy `wlperch` to `~/.local/bin` yourself and use the files in `contrib/` (see the README).

Check the download with `sha256sum -c SHA256SUMS`.

The tarballs contain the binary, the README, the `contrib/` sway, waybar and Neovim files, and the license texts of the embedded fonts, the emoji data, Dear ImGui and the Odin core library (`licenses/`).
