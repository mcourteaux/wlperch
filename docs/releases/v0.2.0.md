wlperch is a quick-settings popup, status bar, lock screen and desktop helper for the sway compositor, in one binary.

**0.2.0 (early / pre-release).** Expect rough edges; bug reports are welcome.

### Changes since 0.1.1
- **Updates from GitHub.** wlperch checks for a new release once a day (`[update] check_daily`), and the main panel's header has an update button: grey when up to date, green when a release is waiting. A click downloads the release for your CPU, verifies it against `SHA256SUMS`, replaces `~/.local/bin/wlperch` and restarts. `wlperch update check` / `wlperch update` do the same from a terminal. Builds you make yourself with `./build.sh` are never replaced (`wlperch --version` says `(dev build)`).
  0.1.x doesn't have the updater yet: update to 0.2.0 by hand once.
- **Your sway file under any name.** Setup recognises wlperch's sway file by its content, so a copy saved as e.g. `45-wlperch.conf` or symlinked from a dotfiles repo is managed (key editor, Update) and written through the link. The generated file starts with a banner saying so.
- **Bare popups.** The bar's volume and timer buttons open just their card, without the panel header and tabs.
- **The low-memory card can be dragged.**

### Platform
- Linux, x86_64 or aarch64 (ARM64)
- Wayland with sway (it uses sway's IPC); some parts also work on other wlroots compositors
- glibc 2.34 or newer (Debian 12, Ubuntu 22.04, Fedora 35 and later)

The aarch64 build is cross-compiled. Its unit tests pass under qemu, but it has not been tried on real ARM hardware yet.

### Runtime dependencies
Most sway desktops already have these installed.
- **Fedora:** `libwayland-client libwayland-egl libglvnd-egl mesa-libEGL libxkbcommon systemd-libs pam-libs fontconfig freetype libstdc++`
- **Debian / Ubuntu:** `libwayland-client0 libwayland-egl1 libegl1 libegl-mesa0 libxkbcommon0 libsystemd0 libpam0g libfontconfig1 libfreetype6 libstdc++6`

Optional tools for some panels (README, "Building"): `pactl`, `busctl`, `curl`, `wl-copy`, `bluetoothctl`, `wlsunset`.

### Install
```sh
tar xzf wlperch-0.2.0-x86_64-linux.tar.gz   # or the aarch64 tarball
cd wlperch-0.2.0-x86_64-linux
./wlperch
```
`./wlperch` opens the setup window. From there it copies itself to `~/.local/bin/wlperch` and can set up the sway integration, the waybar buttons, the config file and the other parts. Each file can be previewed before it is written. You can also copy `wlperch` to `~/.local/bin` yourself and use the files in `contrib/` (see the README).

Check the download with `sha256sum -c SHA256SUMS`.

The tarballs contain the binary, the README, the `contrib/` sway, waybar and Neovim files, and the license texts of the embedded fonts, the emoji data, Dear ImGui and the Odin core library (`licenses/`).
